# micpa
Réplica en Django del sitio web, con secciones de eventos, mensajes y podcast, blog de notas, información para nuevos visitantes y grupos de alcance, gestionables desde el panel de administración.

micpa_web/
├── core/            # home, visítanos, configuración global, slider
├── events/          # eventos
├── sermons/         # podcast / mensajes
├── blog/            # notas
├── newcomers/       # formulario "Soy nuevo"
├── templates/       # todas las plantillas, organizadas por app
├── static/          # css, js e imágenes fijas (logo, iconos)
├── media/           # subidas desde el admin (posters, portadas)
